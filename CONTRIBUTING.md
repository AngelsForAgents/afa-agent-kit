# Contributing

Contributions that reduce discovery or application friction are welcome.

1. Open an issue describing the proposed change.
2. Keep the toolkit small, framework-neutral, and safe for unattended agents.
3. Do not add secrets, production application data, or real controller information to fixtures.
4. Run `npm test` before opening a pull request.
5. Clearly identify any behavior that transmits data or creates an external side effect.

Changes to opportunity terms, legal language, schemas, or submission behavior must remain consistent with the live resources at <https://angelsforagents.com>.
